# ☁️ Sección 19: Kubernetes - Despliegue en AWS EKS (Elastic Kubernetes Service)

## 📌 Nota de Revisión Arquitectónica

### ⚠️ Limitación de Entorno:

Esta sección se aborda exclusivamente de manera teórica y conceptual, ya que no se dispone de una cuenta activa con
créditos en Amazon Web Services (AWS) para replicar los laboratorios en vivo.

### Objetivo de Aprendizaje:

Utilizar este bloque de videos como una guía de referencia visual y de arquitectura para comprender cómo se traslada,
aprovisiona y escala en la nube pública de producción (AWS EKS) toda la infraestructura que previamente diseñamos,
contenerizamos y probamos de manera local en nuestro clúster de Minikube.
